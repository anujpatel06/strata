Density changes how much fits on screen without changing a single component. Comfortable suits forms and consumer flows; compact suits tables and tools people use all day.

## Set the density

Each tenant has a default in its `brand.json` — Vela, a banking dashboard, defaults to compact. Override it with an attribute, or per region with `ThemeScope`:

```html
<html data-syntara-theme="vela" data-syntara-density="comfortable">
```

```tsx
<ThemeScope theme="harbor" density="compact">
  <ClaimsTable />
</ThemeScope>
```

## What changes

Density is a handful of variables. Components size themselves from these, so there is no `size="compact"` prop to thread through your code.

<DensityTable />

Type size stays the same in both densities, and so does the space scale — only the spacing components choose from it changes.

## Hit targets

Compact controls are still at least 24 × 24 px, the WCAG 2.2 minimum target size (2.5.8).
