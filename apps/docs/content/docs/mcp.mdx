The Strata MCP server lets AI coding agents look up components, tokens and usage rules while they write code, and check their own work. It reads the same `meta.json` files as these pages.

<Callout tone="info" title="Not published yet">
  The server works from a checkout of the repo today. `npx @strata/mcp` arrives with the npm release. The agent eval that measures whether the server helps is running; its results will be linked here, whatever they show.
</Callout>

`get_example` is an addition to the six tools in the project brief. Agents copy working code more reliably than they read prop tables.

It also serves two files as resources: `strata://agents` (`AGENTS.md`, the rules for agents) and `strata://governance`.

## Read-only

No tool writes a file. `audit_snippet` returns each fix marked `safe: true` or `safe: false`. A safe fix has one right answer, such as the exact token for a raw value. An agent may apply safe fixes on its own; everything else is a suggestion for a person. See the trust levels in [Governance](/docs/governance#agent-trust-levels).

## Set it up

Run `pnpm install` in a checkout of the repo, then point your client at the server. Replace `/path/to/strata` with the path of your checkout.

```sh
claude mcp add strata -- node /path/to/strata/packages/mcp/bin/cli.mjs
```

For Cursor (`.cursor/mcp.json`) and other clients that use the same format:

```json
{
  "mcpServers": {
    "strata": {
      "command": "node",
      "args": ["/path/to/strata/packages/mcp/bin/cli.mjs"]
    }
  }
}
```

VS Code uses `.vscode/mcp.json` with a `servers` key; the full snippet is in the package’s README. The Cursor and VS Code snippets follow those clients’ documented formats and haven’t been tried against the clients themselves.

## The drift auditor

`audit_snippet` runs the same engine as the command-line auditor:

```sh
pnpm drift src --format text
```

It looks for raw colours, sizes off the scale, written-out fonts, native elements where a component exists, physical properties, controls with no accessible name, and deprecated APIs. Every finding says what to write instead. `--fix` applies the safe ones.

The auditor reads one file at a time, so it can’t see a name or a value that arrives through props. Its limits are listed in the package’s README.
