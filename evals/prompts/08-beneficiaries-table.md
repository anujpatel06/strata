Build a beneficiaries list for a banking app. Each row shows the person's name, bank, the last four digits of the account and when they were added. Each row has icon-only actions to edit and to remove. Rows can be selected, and a bar appears with "Remove selected" when any are. The list can be sorted by name and by date added.
