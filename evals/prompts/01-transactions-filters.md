Build a transactions page for a banking app. Show a table of 12 recent transactions with date, description, category, status and amount. Above the table, add a search field, a category filter and a date range filter. Add an "Export CSV" action. Status is one of completed, pending or failed. Include the empty state that shows when no transaction matches the filters.
